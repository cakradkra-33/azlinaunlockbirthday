# Made For You — Birthday Edition v2

Versi recreate mandiri yang menggabungkan konsep dari:
- madeforanita.vercel.app
- happybirthday-salome-website.vercel.app

Bukan source code asli dari kedua website.

## Jalankan
Extract ZIP → buka folder di VS Code → buka `index.html`.
Paling mudah gunakan extension Live Server.

Tidak membutuhkan Node.js atau npm.

## Fitur
Opening hadiah, birthday hero, foto pribadi, rain text, countdown, musik lokal, pengaturan, ID/EN, memory cards, buku/surat animasi, efek hati, Make a Wish, responsive mobile, dan localStorage.

## Edit
Gunakan tombol ⚙ untuk mengganti teks, warna, countdown, foto, dan musik.

Foto dan musik yang dipilih dari komputer hanya digunakan di browser.

## Event section
Bagian paling bawah sekarang memiliki section informasi acara seperti referensi: venue card, tanggal, waktu, dan dress code. Semua aset event bersifat lokal.
